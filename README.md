## Componentes
| Componente | Função |
| :--- | :--- |
| **J1** | Entrada da tensão AC |
| **BR1** | Ponte retificadora |
| **C1** | Capacitor de filtragem |
| **C2** | Capacitor de desacoplamento |
| **U1 (7812)** | Regulador de tensão |
| **C3** | Capacitor de estabilização |
| **R1** | Limitador de corrente |
| **D1** | LED indicador |
| **J2** | Saída da fonte |

## Como usar
1. Abra o arquivo .pdsprj no Proteus.

2. Na aba ARES, você encontra o layout da placa.

3. Na aba 3D Viewer, você pode ver o resultado final da montagem.
