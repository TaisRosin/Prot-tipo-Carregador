# Fonte de Alimentação 12V
Projeto de uma fonte de carregador desenvolvida no Proteus, que converte sinal AC para uma saída 12V DC.

## O que há neste repositório?
* **Esquemático:** Circuito completo com ponte retificadora, filtragem e regulador 7812.

* **Layout PCB:** Desenho das trilhas e furação pronto para fabricação.

* **Modelo 3D:** Visualização completa da placa montada com componentes.

## Componentes Utilizados
* **Ponte de Diodos:** Para retificação de onda completa.

* **Capacitor 1000μF:** Filtro para reduzir ruídos e oscilações.

* **CI 7812:** Regulador de tensão de saída fixa.

* **LED de Status:** Indica que a fonte está ligada e operando.

## Como usar
1. Abra o arquivo .pdsprj no Proteus.

2. Na aba ARES, você encontra o layout da placa.

3. Na aba 3D Viewer, você pode ver o resultado final da montagem.
